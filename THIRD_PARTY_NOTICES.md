# Componenti di terze parti

NILES è distribuito con licenza [AGPL-3.0-or-later](LICENSE). Il repository include però, già pronti all'uso,
alcuni componenti di terze parti nella cartella `public/vendor/`. Restano soggetti alle loro licenze, che qui
sotto sono riportate insieme alla versione inclusa e alla fonte. Le indicazioni di copyright e licenza sono
mantenute anche nelle intestazioni dei file.

Le icone di Font Awesome Free richiedono l'attribuzione prevista dalla licenza CC BY 4.0, riportata
nell'intestazione dei file CSS inclusi.

Le librerie PHP e JavaScript installate tramite Composer e npm (vedi `composer.lock` e `package-lock.json`)
mantengono ciascuna la propria licenza, indicata nei rispettivi pacchetti.
